# 粒子俄罗斯方块

一个基于 Pygame 的粒子系统俄罗斯方块游戏，具有独特的物理引擎和动画效果。

## 项目简介

这是一个创新的俄罗斯方块游戏，方块由多个小粒子组成。当方块落下后，粒子会根据物理规则自动分散，形成平滑的动画效果。游戏具有以下特色：

- 🎨 **粒子系统**：每个方块由 5×5=25 个粒子组成
- 🌊 **物理引擎**：粒子自动分散，相邻列高度差不超过1
- 🎯 **消除机制**：相同颜色的连通区域横跨整个地图时消除
- 📊 **得分系统**：消除区域的粒子数 × 区域的最高高度值
- ⚠️ **警戒线**：粒子超过警戒线时游戏结束

## 游戏规则

### 基本玩法

1. **方块下落**：方块从顶部自动下落，玩家可以控制左右移动和快速下落
2. **粒子分散**：方块落地后，粒子会根据物理规则自动分散：
   - 底部没有粒子时，自动落下填充
   - 相邻两列高度差不超过1，否则高列的粒子移到低列
   - 如果中间列比两边都高超过1，随机选择一边移动
3. **消除条件**：当相同颜色的连通区域横跨整个地图（从最左边到最右边）时，该区域会被消除
4. **消除后处理**：消除后，剩余粒子先垂直下落填补空隙，然后按照分散规则重新分配

### 得分规则

- **得分计算**：消除区域的粒子数 × 区域的最高高度值
- 得分显示在屏幕左上角

### 游戏结束

- 当有粒子超过红色警戒线时，游戏结束
- 按 `R` 键可以重新开始游戏

## 操作说明

| 按键 | 功能 |
|------|------|
| `←` (左箭头) | 向左移动方块 |
| `→` (右箭头) | 向右移动方块 |
| `↓` (下箭头) | 快速下落 |
| `R` | 游戏结束后重新开始 |

## 游戏配置

可以在 `config.py` 中修改以下配置：

```python
BLOCK_SIZE = 5          # 每个方块包含的粒子数（5×5=25）
CELL_SIZE = 6           # 每个粒子的像素大小
GRID_WIDTH = 60         # 网格宽度（粒子单位）
GRID_HEIGHT = 150       # 网格高度（粒子单位）
WARNING_LINE_Y = 30     # 警戒线位置
FALL_SPEED = 500        # 方块下落速度（毫秒）
ANIMATION_SPEED = 0.1   # 动画速度
```

## 技术特点

### 模块化设计

项目采用模块化架构，各模块职责清晰：

- **config.py**：集中管理所有配置常量
- **particle.py**：粒子实体类，处理粒子的位置和动画
- **block.py**：方块类，生成随机形状
- **physics.py**：物理引擎，计算粒子轨迹和分散规则
- **renderer.py**：渲染器，处理所有绘制逻辑
- **input_handler.py**：输入处理器，处理用户输入
- **game.py**：游戏主类，协调各个模块

### 动画系统

- 粒子移动使用平滑的线性插值动画
- 支持多阶段动画，确保动画连续性
- 所有粒子同时移动，视觉效果流畅

### 物理引擎

- 实现了智能的粒子分散算法
- 确保相邻列高度差不超过1
- 保持每列内部粒子的颜色顺序

## 常见问题

### Q: 游戏运行报错 "ModuleNotFoundError: No module named 'pygame'"

A: 请先安装 Pygame：
```bash
pip install pygame
```

### Q: 游戏窗口太大或太小

A: 修改 `config.py` 中的 `CELL_SIZE`、`GRID_WIDTH` 和 `GRID_HEIGHT` 参数

### Q: 游戏运行太慢或太快

A: 修改 `config.py` 中的 `FALL_SPEED` 和 `ANIMATION_SPEED` 参数
